# Data, provenance and limits

- The 3,798- and 10,000-skill libraries are distinct evaluation scopes. Expanded
  acceptable answers apply only to the latter. The 1,051 added-source decisions
  must not be mistaken for the total number of acceptable answers or requests.
- Original labels and rankings are frozen. Exporting a compact join does not
  approve new answers, repair an extraction, or run another experiment.
- Model-assisted review and researcher approval are described in the thesis.
  They must not be relabelled as independent full-library human annotation.
- Early smaller-library exact-analysis prerequisites are missing. Its historical
  receipt is retained for inspection; its old command is not advertised as runnable.
- Larger-library per-query scoring is replayable. The lightweight replay does not
  recompute bootstrap intervals, provider billing, wall-clock timings, or extraction.
- Timings and monetary estimates retain their original scopes. BM25 retrieval is local;
  a BM25-plus-Qwen pipeline can still incur Qwen reranking charges.
- Large vectors are stored through Git LFS. Downloading pointers alone is not downloading
  the embeddings. Float64 export preserves stored JSON values; it does not improve model precision.
- Third-party full skill documents, papers, and model weights are not redistributed here.
  Hashes and source bindings preserve identity; exact-text model reruns additionally need
  the original documents and their applicable licences.
- Real `.env` files, tokens, credentials, invoices, private chat logs, personal billing
  observations, cloud-job envelopes, model downloads and scratch snapshots are excluded.
  `.env.example` contains blank optional variables; offline commands do not read it.
- The repository is public. Public access is not a blanket licence grant or a
  certification of upstream rights. This GitHub release is not a DOI archive.
